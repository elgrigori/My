# ΕΦΑΡΜΟΓΗ ΔΙΑΧΕΙΡΗΣΗΣ ΔΡΑΣΕΩΝ ΕΘΕΛΕΟΝΤΙΣΜΟΥ

Η εφαρμογή Διαχείρησης Δράσεων Εθελοντισμού, είναι μία πλατφόρμα που έχει σαν στόχο τη σύνδεση εθελοντών με οργανισμούς που διοργανώνουν δράσεις εθελοντισμού.
Ο σχεδιασμός της εφαρμόγης αποσκοπέι στην διαδικασία εύρεσης δράσεων, δήλωσης συμμετοχής και επικονωνίας, προάγοντας με αυτό τον τρόπο την ενεργή συμμετοχή στην κοινότητα και την ευαισθητοποιήση σε θέματα εθελοντισμού.

## ΛΕΙΤΟΥΡΓΙΕΣ ΤΗΣ ΕΦΑΡΜΟΓΗΣ

### Εγγραφή και Διαχείριση Προφίλ

- Εθελοντές: Δημιουργούν ένα προφίλ με βασικές πληροφορίες (Όνομα, Επώνυμο, Στοιχεία επικοινωνίας(Διεύθυνση, ΤΚ, Πόλη, Τηλέφωνο), Email)
- Οργανισμοί: Δημιουργούν ένα προφίλ με πληροφορίες για τον οργανισμό και τα είδη δράσεων που υποστηρίζουν.
  - Οι πληροφορίες του οργανισμού περιλαμβάνουν Όνομα οργανισμού, Σύντομη περιγραφή του οργανισμού, του οράματος, της αποστολής και των στόχων, Ετος ίδρυσης, Στοιχεία επικοινωνίας(Διεύθυνση, ΤΚ, Πόλη,Τηλέφωνο, Email), ΑΦΜ

### Προβολή και Αναζήτηση Δράσεων

- Λίστα διαθέσιμων δράσεων με πληροφοριές όπως Τίτλος,Κατηγόρια Δράσης, Περιγραφή, Ημερομηνία('Εναρξης, Λήξης), Ώρα, Χρονική Διάρκεια, Τοποθεσία.
- Δυατότητα φιλτραρίσματος με βάση την Τοποθεσία ή την Ημερομήνια ή Κατηγορία Δράσης.

### Καταχώρηση και Διαχείρηση Δράσεων από Οργανισμούς

- Οι οργανισμοί καταχωρούν δράσεις, καθορίζοντας βασικές λεπτομέρειες (Τίτλος,Κατηγόρια Δράσης, Περιγραφή,Αριθμός εθελοντών, Ημερομηνία('Εναρξης, Λήξης), Ώρα, Χρονική Διάρκεια, Τοποθεσία.)
- Προβολή λίστας συμμετοχών για κάθε δράση που έχουν καταχωρήσει.

### Δήλωση Συμμετοχής Εθελοντών

- Οι εθελοντές μπορούν να δηλώσουν συμμετοχή σε δράσεις, επιτρέποντας την εύκολη οργάνωση αν υπάρχει διαθεσιμότητα συμμετοχής στην εκάστοτε δράση.
- Προβολή και διαχείρηση της λίστα των συμμετοχών που έχουν δηλώσει ενδιαφέρον.
  
### ΤΥΠΟΙ ΔΡΑΣΕΩΝ

Όλες οι δράσεις μπορούν να ανήκουν στις παρακάτω κατηγορίες:

- **Δράση Ακτιβισμού**
Οι δράσεις ακτιβισμού αφορούν τα ανθρώπινα δικαιώματα, την προστασία του περιβάλλοντος, της εργασίας, της μόρφωσης κτλ. που παρουσιάζονται με διάφορες μορφές δράσης, όπως υπαίθριες συναυλίες, πορείες, απεργίες, κινητοποιήσεις καθαρισμού, αναδάσωσης κ.λ.π.

- **Δράση Προσφοράς**
Οι δράσεις προσφοράς αποτελούν μια δυναμική μορφή κοινωνικής εμπλοκής, με στόχο την ενίσχυση των ευπαθών κοινωνικών ομάδων και την προώθηση της αλληλεγγύης. Μέσω διαφόρων πρωτοβουλιών, όπως συλλογές τροφίμων, ρούχων και ιατρικού εξοπλισμού, οι δράσεις αυτές συμβάλλουν στην αντιμετώπιση κοινωνικών ανισοτήτων και στη βελτίωση της ποιότητας ζωής των ανθρώπων που έχουν ανάγκη.

- **Δράση Χρηματοδότησης**
Οι δράσεις χρηματοδότησης αποτελούν έναν κρίσιμο μηχανισμό για την ενδυνάμωση και βιωσιμότητα οργανισμών που παρέχουν κρίσιμες υπηρεσίες στην κοινωνία και για την υποστήριξη και υλοποίηση κοινωνικών, περιβαλλοντικών και εκπαιδευτικών πρωτοβουλιών. Μέσω στοχευμένων εκστρατειών συγκέντρωσης χρημάτων εξασφαλίζονται οι απαραίτητοι οικονομικοί πόροι για την ανάπτυξη και τη βιωσιμότητα σημαντικών προγραμμάτων.

## ΑΠΑΙΤΗΣΕΙΣ ΕΦΑΡΜΟΓΗΣ

### ΔΙΑΧΕΙΡΙΣΗ ΧΡΗΣΤΩΝ (ΕΘΕΛΟΝΤΕΣ ΚΑΙ ΟΡΓΑΝΙΣΜΟΙ)

Η εφαρμογή υποστηρίζει 2 τύπους χρηστών, **ΕΘΕΛΟΝΤΕΣ** και **ΟΡΓΑΝΙΣΜΟΙ**, οι οποίοι έχουν τη δυνατότητα δημιουργίας λογαριασμού.

- Οι **Εθελοντές** μπορούν να δημιουργήσουν λογαριασμούς καταχωρόντας τα παρακάτω στοιχεία
  - (*'Ονομα, Επώνυμο, Στοιχεία διεύθυνσης(Οδός, Αριθμός, ΤΚ, Πόλη ), Τηλέφωνο,Email*)
- Οι **Οργανισμοί** μπορούν να δημιουργήσουν λογαριασμούς καταχωρόντας τα παρακάτω στοιχεία
  - (*Όνομα οργανισμού, Τύπος Δράσης (Ακτιβισμός,Προσφορά, Χρηματοδότηση), Σύντομη περιγραφη του οργανισμού, Περιγραφή της αποστολής και των στόχων, Έτος Ίδρυσης, Στοιχεία διεύθυνσης(Οδός, Αριθμός, ΤΚ, Πόλη ), Τηλέφωνο,Email, ΑΦΜ*)
- Κάθε χρήστης μπορεί να έχει μόνο **ένα** λογαριασμό.
- Κάθε χρήστης έχει τη δυνατότητα **Διαχείρισης Προφίλ**, ενημερώνοντας τα στοιχεία που έχει καταχωρήσει κατά την εγγραφή του.

### Αναζήτηση και Προβολή Δράσεων και Εθελοντών

- Οι **Εθελοντές** μπορούν να δούν τις διαθέσιμες δράσεις που έχουν καταχωρήσει οι οργανισμοί.
- Οι **Οργανισμοί** μπορούν να δούν τις διαθέσιμες δράσεις που έχουν καταχωρήσει οι ίδιοι, καθώς και τις δράσεις που έχουν καταχωρηθεί από τους υπόλοιπους οργανισμούς χωρίς να έχουν την δυνατότητα τροποποίησης αυτών.
- Οι **Οργανισμοί** μπορού να δουν τη λίστα των εθελοντών κάθε δράσης.
- Οι **Χρήστες** μπορούν να αναζητήσουν δράσεις με βάση την Τοποθεσία, την Ημερομήνια ή την Τύπο Δράσης.

### Καταχώρηση και Διαχείρηση Δράσεων από τους Οργανισμού

Οι **Οργανισμοί** μπορούν να καταχωρούν όσες δράσεις επιθυμούν με τις παρακάτω πληροφορίες

- Τίτλος, Τύπος Δράσης, Περιγραφή Δράσης, Ημερομηνία('Εναρξης, Λήξης).
  - Στη περίπτωση **Δράσης Ακτιβισμού**, ο **Οργανισμός** πρέπει να καταχώρησει επιπλέον την Τοποθεσία, Διαθέσιμες Θέσεις, Ελάχιστος και Μέγιστος Αριθμός Συμμετοχών
  - Στη περίπτωση **Δράσης Προσφοράς**, ο **Οργανισμός** πρέπει να καταχώρησει επιπλέον την Τοποθεσία και τον απαιτούμενο αριθμών τεμαχίων που αναμένεται να συγκεντρωθούν.
  - Στη περίπτωση **Δράσης Χρηματοδότησης**, ο **Οργανισμός** πρέπει να καταχώρησει επιπλέον το αναμένο ποσό για συγκέντρωση.
Οι οργανισμοί μπορούν να **τροποποιήσουν** ή να **ακυρώσουν** μια δράση μέχρι **12 ώρες** πριν την έναρξη της αντίστοιχης δράσης.

### Συμμετόχη Εθελοντών σε Δράσεις

- Οι **Εθελοντές** έχουν τη δυνατότητα να συμμετάσχουν σε **όσες** δράσεις επιθυμούν.
- Οι **Εθελοντές** **δεν** έχουν τη δυνατότητα να συμμετάσχουν σε δράσεις που πραγματοποιούνται **ταυτόχρονα**.
- Οι **Εθελοντές** έχουν τη δυνατότητα να **ακυρώσουν** τη συμμετοχή τους μέχρι **12 ώρες** πρίν την έναρξη της αντίστοιχης δράσης.

- **Συμμετοχή σε Δράση Προσφοράς**
  
- Κάθε συμμέτοχή σε προσφόρα μπορεί να προσφέρει πολλά προϊόντα.

### ΕΙΔΟΠΟΙΗΣΕΙΣ

- Οι **Εθελοντές** θα λαμβάνουν **Επιβεβαίωση Συμμετοχής** μετά την εκδήλωση ενδιαφέροντος σε αυτές.
- Σε περίπτωση **τροποποίησης** ή **διαγραφής** μιας δράσης απο έναν οργανισμό, οι εθελοντές θα λαμβάνουν **Είδοποίηση**.

### ΤΥΠΟΙ ΔΡΑΣΕΩΝ ΕΘΕΛΟΝΤΙΣΜΟΥ

- Oι δράσεις μπορούν να ανήκουν στις παρακάτω κατηγορίες:

- **Δράση Ακτιβισμού**
  
  - Στην δράση αυτή, ο **Οργανισμός** πρέπει να ορίσει τον ελάχιστο και μέγιστο αριθμό συμμετοχών, τις διαθέσιμες θέσεις καθώς και την τοποθεσία που θα λάβει μέρος η δράση.
  - Στην περίπτωση μη συμπλήρωσης του απαιτούμενου αριθμού συμμετοχών, η δράση θα **ακυρώνεται** αυτόματα.
  - Στη δράση αυτή μπορεί να λάβει μέρος όποιος εθελοντής επιθυμεί.

- **Δράση Προσφοράς**
  
  - Στην δράση αυτή, ο **Οργανισμός** ορίζει, μέσω της περιγράφης της δράσης, τον τύπο προϊόντων που αποσκοπεί η δράση, τον απαιτούμενο αριθμών τεμαχίων και την τοποθεσία που θα λαμβάνει χώρα η δράση.
  - Σε περίπτωση κάλυψης των αναγκών πριν την ημερομηνία λήξης, η δράση θα **ολοκληρώνεται**.
  - Κάθε δράση προσφοράς μπορεί να έχει από **1 και παραπάνω προϊόντα**.

- **Δράση Χρηματοδότησης**

  - Στην δράση αυτή, ο **Οργανισμός** ορίζει το απαιτούμενο πόσο που θέλει να συγκεντρώσει.
  - Σε περίπτωση που το ποσό συγκεντρωθεί, η δράση θα θεωρείται ολοκληρώμενη και δεν θα μπορεί να λάβει μέρος σε αυτήν άλλος εθελοντής.
  - Σε περίπτωση που η δράση λήξει και δεν έχει συγκεντρωθεί το απαιτούμενο ποσό, το πόσο δεν θα επίστρεφεται στους εθελοντές αλλά θα διαμένεται στον τελικό αποδέκτη της δράσης.
